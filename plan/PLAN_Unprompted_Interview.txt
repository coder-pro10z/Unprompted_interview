### 2. Core Engine Design (`@speech-coach/core`)

The core library is written in vanilla TypeScript with zero framework dependencies.

#### State Machine

The session follows a predictable state flow:

* `IDLE`: Displays the assigned topic and preparation controls.
* `PREPARING`: Countdown timer for reading the prompt and organizing thoughts.
* `SPEAKING`: Camera and microphone activate; live video feed is displayed, and audio/video is recorded.
* `PROCESSING`: Recording stops, media chunks are packaged into a `Blob`, and uploaded for AI analysis.
* `REVIEW`: Displays synchronized video playback, transcript, and structured AI feedback.

#### Key Modules

1. **`MediaStreamManager`**: Handles `navigator.mediaDevices.getUserMedia()`, device selection, permissions, and stream cleanup.
2. **`SessionTimer`**: Emits tick events, remaining time, elapsed time, and threshold triggers (e.g., auto-transition from prep to speaking).
3. **`AudioAnalyzer`**: Uses `AudioContext` and `AnalyserNode` to compute real-time decibel levels for audio visualizers and silence tracking.
4. **`MediaRecorderWrapper`**: Captures video/audio chunks with standard codecs (`video/webm;codecs=vp9,opus` or fallback `mp4`) and returns exportable blobs.

### 4. AI Feedback Pipeline

#### Step 1: Ingestion & Transcription

* The client sends the recorded audio/video blob to the backend.
* Audio track is extracted and passed to a Speech-to-Text model (e.g., OpenAI Whisper or Deepgram) to produce:
* Full transcript.
* Word-level timestamps (for detecting pauses and calculating speaking rate).



#### Step 2: Linguistic & Delivery Evaluation

The transcript and timing data are evaluated against the assigned topic using an LLM pipeline producing structured JSON:

* **Fluency & Pacing**: Words Per Minute (WPM), hesitation duration, and pause distribution.
* **Filler Word Tracking**: Exact occurrences and timestamps for fillers (*"um"*, *"ah"*, *"like"*, *"you know"*).
* **Topic Adherence & Content Structure**: Relevance score, key arguments addressed, clarity of reasoning.
* **Grammar & Vocabulary**: Grammar corrections, tone analysis, and vocabulary variety/enhancements.

#### Example Structured Output Schema:

```json
{

  "metrics": {
```

### 1. Fastest Backend Implementation (`server.js`)

```javascript
import express from 'express';
import multer from 'multer';
import cors from 'cors';
import { GoogleGenAI, Type } from '@google/genai';

const app = express();
const upload = multer({ storage: multer.memoryStorage() });
const ai = new GoogleGenAI({ apiKey: process.env.GEMINI_API_KEY });

app.use(cors());
app.use(express.json());

// Single endpoint: Audio/Video upload -> AI Review
app.post('/api/review-speech', upload.single('media'), async (req, res) => {
  try {
    const { topic, durationSeconds, mode } = req.body;
    const file = req.file;

    if (!file) {
      return res.status(400).json({ error: 'No audio/video file provided' });
    }

    const prompt = `
      You are an expert speech coach. Analyze the user's spoken response on the topic: "${topic}".
      Mode: ${mode || 'Off the cuff'} (Target duration: ${durationSeconds || 60} seconds).
      Evaluate their speech following the 3-part framework:
      1. What? (The concept/definition)
      2. So what? (Why it matters/impact)
      3. Now what? (Actionable takeaways or future outlook)

      Provide structured analysis for fluency, filler words (e.g., "um", "ah", "like"), pacing (WPM), and concrete coaching tips.
    `;

    const response = await ai.models.generateContent({
      model: 'gemini-1.5-flash',
      contents: [
        {
          role: 'user',
          parts: [
            { text: prompt },
            {
              inlineData: {
                mimeType: file.mimetype,
                data: file.buffer.toString('base64'),
              },
            },
          ],
        },
      ],
      generationConfig: {
        responseMimeType: 'application/json',
        responseSchema: {
          type: Type.OBJECT,
          properties: {
            overallScore: { type: Type.NUMBER },
            transcript: { type: Type.STRING },
            wordsPerMinute: { type: Type.NUMBER },
            fillerWords: {
              type: Type.ARRAY,
              items: {
                type: Type.OBJECT,
                properties: {
                  word: { type: Type.STRING },
                  count: { type: Type.NUMBER },
                },
              },
            },
            structureEvaluation: {
              type: Type.OBJECT,
              properties: {
                whatCovered: { type: Type.BOOLEAN },
                soWhatCovered: { type: Type.BOOLEAN },
                nowWhatCovered: { type: Type.BOOLEAN },
                feedback: { type: Type.STRING },
              },
            },
            strengths: { type: Type.ARRAY, items: { type: Type.STRING } },
            areasToImprove: { type: Type.ARRAY, items: { type: Type.STRING } },
          },
          required: ['overallScore', 'transcript', 'wordsPerMinute', 'structureEvaluation', 'strengths', 'areasToImprove'],
        },
      },
    });

    const result = JSON.parse(response.text);
    return res.json(result);
  } catch (error) {
    console.error('AI Analysis failed:', error);
    return res.status(500).json({ error: 'Failed to analyze speech' });
  }
});

app.listen(5000, () => console.log('Speech Review Server running on http://localhost:5000'));
```

### 2. Frontend: Modular Core Hook (`useSpeechSession.js`)

This hook encapsulates the **Camera stream**, **MediaRecorder**, **Precision Timer**, and **Audio Synthesizer** so it can be plugged into any React project.

```javascript
import { useState, useRef, useEffect, useCallback } from 'react';

export function useSpeechSession({ speechDuration = 60, apiUrl = 'http://localhost:5000/api/review-speech' }) {
  const [sessionState, setSessionState] = useState('idle'); // 'idle' | 'recording' | 'processing' | 'review'
  const [timeRemaining, setTimeRemaining] = useState(speechDuration);
  const [videoStream, setVideoStream] = useState(null);
  const [recordedUrl, setRecordedUrl] = useState(null);
  const [aiFeedback, setAiFeedback] = useState(null);

  const mediaRecorderRef = useRef(null);
  const recordedChunksRef = useRef([]);
  const timerIntervalRef = useRef(null);

  // Initialize camera and microphone
  const startRecording = useCallback(async (topic, mode = 'Off the cuff') => {
    try {
      recordedChunksRef.current = [];
      const stream = await navigator.mediaDevices.getUserMedia({
        video: { width: 1280, height: 720, facingMode: 'user' },
        audio: true,
      });

      setVideoStream(stream);
      setSessionState('recording');
      setTimeRemaining(speechDuration);

      const recorder = new MediaRecorder(stream, { mimeType: 'video/webm;codecs=vp8,opus' });
      mediaRecorderRef.current = recorder;

      recorder.ondataavailable = (e) => {
        if (e.data && e.data.size > 0) recordedChunksRef.current.push(e.data);
      };

      recorder.onstop = async () => {
        // Stop stream tracks
        stream.getTracks().forEach((track) => track.stop());
        setVideoStream(null);

        const videoBlob = new Blob(recordedChunksRef.current, { type: 'video/webm' });
        setRecordedUrl(URL.createObjectURL(videoBlob));
        setSessionState('processing');

        // Send to backend
        const formData = new FormData();
        formData.append('media', videoBlob, 'speech.webm');
        formData.append('topic', topic);
        formData.append('durationSeconds', speechDuration);
        formData.append('mode', mode);

        try {
          const res = await fetch(apiUrl, { method: 'POST', body: formData });
          const feedback = await res.json();
          setAiFeedback(feedback);
          setSessionState('review');
        } catch (err) {
          console.error(err);
          setSessionState('idle');
        }
      };

      recorder.start(1000);

      // Start countdown
      const endTime = Date.now() + speechDuration * 1000;
      timerIntervalRef.current = setInterval(() => {
        const remaining = Math.max(0, Math.ceil((endTime - Date.now()) / 1000));
        setTimeRemaining(remaining);
        if (remaining <= 0) {
          clearInterval(timerIntervalRef.current);
          recorder.stop();
        }
      }, 100);
    } catch (err) {
      console.error('Camera/Mic permission denied:', err);
    }
  }, [speechDuration, apiUrl]);

  const stopRecording = useCallback(() => {
    if (timerIntervalRef.current) clearInterval(timerIntervalRef.current);
    if (mediaRecorderRef.current && mediaRecorderRef.current.state === 'recording') {
      mediaRecorderRef.current.stop();
    }
  }, []);

  const resetSession = useCallback(() => {
    stopRecording();
    setSessionState('idle');
    setAiFeedback(null);
    setRecordedUrl(null);
    setTimeRemaining(speechDuration);
  }, [stopRecording, speechDuration]);

  return {
    sessionState,
    timeRemaining,
    videoStream,
    recordedUrl,
    aiFeedback,
    startRecording,
    stopRecording,
    resetSession,
  };
}

```

### 4. Angular Equivalent Adapter (`speech-session.service.ts`)

To port the exact same capability into an **Angular** app, use this standalone service:

```typescript
import { Injectable, signal } from '@angular/core';
import { HttpClient } from '@angular/common/http';

export interface SpeechFeedback {
  overallScore: number;
  wordsPerMinute: number;
  strengths: string[];
  areasToImprove: string[];
}

@Injectable({ providedIn: 'root' })
export class SpeechSessionService {
  state = signal<'idle' | 'recording' | 'processing' | 'review'>('idle');
  timeRemaining = signal<number>(60);
  feedback = signal<SpeechFeedback | null>(null);
  recordedBlobUrl = signal<string | null>(null);

  private mediaRecorder: MediaRecorder | null = null;
  private stream: MediaStream | null = null;
  private chunks: Blob[] = [];
  private timer: any = null;

  constructor(private http: HttpClient) {}

  async start(topic: string, durationSeconds: number = 60) {
    this.chunks = [];
    this.stream = await navigator.mediaDevices.getUserMedia({ video: true, audio: true });
    this.state.set('recording');
    this.timeRemaining.set(durationSeconds);

    this.mediaRecorder = new MediaRecorder(this.stream);
    this.mediaRecorder.ondataavailable = (e) => { if (e.data.size > 0) this.chunks.push(e.data); };
    
    this.mediaRecorder.onstop = () => {
      this.stream?.getTracks().forEach((t) => t.stop());
      const blob = new Blob(this.chunks, { type: 'video/webm' });
      this.recordedBlobUrl.set(URL.createObjectURL(blob));
      this.state.set('processing');

      const formData = new FormData();
      formData.append('media', blob, 'speech.webm');
      formData.append('topic', topic);

      this.http.post<SpeechFeedback>('http://localhost:5000/api/review-speech', formData)
        .subscribe({
          next: (res) => {
            this.feedback.set(res);
            this.state.set('review');
          },
          error: () => this.state.set('idle')
        });
    };

    this.mediaRecorder.start(1000);
    this.timer = setInterval(() => {
      this.timeRemaining.update((v) => {
        if (v <= 1) {
          clearInterval(this.timer);
          this.mediaRecorder?.stop();
          return 0;
        }
        return v - 1;
      });
    }, 1000);
  }

  stop() {
    if (this.timer) clearInterval(this.timer);
    this.mediaRecorder?.stop();
  }
}

```

```typescript
    }
    video { width: 100%; height: 100%; object-fit: cover; transform: scaleX(-1); }
    .btn {
      background: var(--accent); color: #1a1612; border: none;
      padding: 0.8rem 1.5rem; border-radius: 999px; font-weight: 600; cursor: pointer;
    }
  `;

  async startSpeaking() {
    this.chunks = [];
    this.timeRemaining = this.duration;
    this.stream = await navigator.mediaDevices.getUserMedia({ video: true, audio: true });
    this.sessionState = 'recording';

    this.mediaRecorder = new MediaRecorder(this.stream);
    this.mediaRecorder.ondataavailable = (e) => this.chunks.push(e.data);
    this.mediaRecorder.onstop = () => this.handleStop();
    this.mediaRecorder.start(1000);

    const videoEl = this.shadowRoot?.querySelector('video');
    if (videoEl) videoEl.srcObject = this.stream;

    this.timerInterval = setInterval(() => {
      this.timeRemaining--;
      if (this.timeRemaining <= 0) this.stopSpeaking();
    }, 1000);
  }

  stopSpeaking() {
    clearInterval(this.timerInterval);
    this.mediaRecorder?.stop();
    this.stream?.getTracks().forEach((t) => t.stop());
  }

  private async handleStop() {
    this.sessionState = 'processing';
    const blob = new Blob(this.chunks, { type: 'video/webm' });
    const formData = new FormData();
    formData.append('media', blob);
    formData.append('topic', this.topic);

    try {
      const res = await fetch(this.apiUrl, { method: 'POST', body: formData });
      this.feedback = await res.json();
      this.sessionState = 'review';
      this.dispatchEvent(new CustomEvent('speech-completed', { detail: this.feedback }));
    } catch {
      this.sessionState = 'idle';
    }
  }

  render() {
    return html`
      <div>
        <button class="btn" @click="${this.startSpeaking}">Start Speaking (${this.duration}s)</button>

        ${this.sessionState === 'recording'
          ? html`
              <div class="modal">
                <div class="camera-circle">
                  <video autoplay playsinline muted></video>
                </div>
                <h2>0:${this.timeRemaining.toString().padStart(2, '0')}</h2>
                <button class="btn" @click="${this.stopSpeaking}">Finish</button>
              </div>
            `
          : ''}
      </div>
    `;
  }
}
```

#### Step 1: Headless Core (`@speech-coach/core`)

Exports the state machine and audio/video pipeline with zero framework dependencies.

```typescript
// packages/core/src/index.ts
export type CoachState = 'idle' | 'recording' | 'processing' | 'review';

export interface SpeechCoachConfig {
  apiUrl: string;
  duration?: number;
  onStateChange?: (state: CoachState) => void;
  onTick?: (remaining: number) => void;
  onFeedback?: (feedback: any) => void;
}

export class SpeechCoachCore {
  private config: SpeechCoachConfig;
  private recorder?: MediaRecorder;
  private stream?: MediaStream;
  private chunks: Blob[] = [];
  private timer?: any;

  constructor(config: SpeechCoachConfig) {
    this.config = config;
  }

  async start(topic: string) {
    this.chunks = [];
    this.stream = await navigator.mediaDevices.getUserMedia({ video: true, audio: true });
    this.recorder = new MediaRecorder(this.stream);
    this.recorder.ondataavailable = (e) => this.chunks.push(e.data);
    this.recorder.onstop = () => this.process(topic);
    this.recorder.start();
    this.config.onStateChange?.('recording');

    let remaining = this.config.duration || 60;
    this.timer = setInterval(() => {
      remaining--;
      this.config.onTick?.(remaining);
      if (remaining <= 0) this.stop();
    }, 1000);

    return this.stream;
  }

  stop() {
    clearInterval(this.timer);
    this.recorder?.stop();
    this.stream?.getTracks().forEach((t) => t.stop());
  }

  private async process(topic: string) {
    this.config.onStateChange?.('processing');
    const blob = new Blob(this.chunks, { type: 'video/webm' });
    const formData = new FormData();
    formData.append('media', blob);
    formData.append('topic', topic);

    const res = await fetch(this.config.apiUrl, { method: 'POST', body: formData });
    const data = await res.json();
    this.config.onFeedback?.(data);
    this.config.onStateChange?.('review');
  }
}
```

### Publishing & Distribution Checklist

1. **Build Tooling (`tsup` / `vite`)**: Configure `tsup` in each package to generate both `esm` (`index.mjs`) and `cjs` (`index.cjs`) along with `.d.ts` declaration maps.
2. **NPM Distribution**:
* Set `"main": "./dist/index.cjs"`, `"module": "./dist/index.mjs"`, `"types": "./dist/index.d.ts"`.
* Publish using `npm publish --access public` (or to a private npm registry like Verdaccio / GitHub Packages).


3. **Local Testing Before Publish**: Run `npm link` or `yalc` to test integration in local Angular and React test apps without publishing to npm.
